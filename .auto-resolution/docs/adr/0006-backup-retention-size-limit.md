# 备份保留策略：单文件覆盖模式 + 总量限制

保持当前 filename.bak 单文件覆盖模式不变（同文件只保留最新备份——隐私清理工具用户不需要历史版本，只需要"清理前的原始"）。加总量限制：定时扫描备份目录，如果总大小超过阈值（如 5GB），按最旧优先删除。配置从 string retention 改为 int max_size_mb。

## Considered Options

- **count-based 保留**：需要改命名为带序号或时间戳，迁移逻辑复杂。被否决——过度工程。
- **time-based 保留**：假设备份按天生成，但实际按文件处理触发。被否决——不直观。
