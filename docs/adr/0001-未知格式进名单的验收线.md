# 未知格式进名单的验收线（宽线）

issue #8（2026-11-09 拍板）：候选格式是否进 `allowed_extensions`，按宽线划——结构不坏 + EXIF/XMP/GPS 等主要隐私信息删得掉，就算「能清」；删不掉的尾巴在 README 与审计里如实写「部分清理」，不谎报「全部清除」。按这条线：WebP、GIF、PSD 进名单（复用 Png 族命令 `-all= --icc_profile:all`），视频六个扩展名维持现役，JXL 继续跳过（jbrd 实测坐实：擦完的 JXL 里 `strings` 都能抠出原 JPEG 的 APP13/COM，且擦除会破坏无损还原）。同时拍板 ICC 统一保留：Png 族默认不再删 iCCP（现役 PNG/APNG 行为变更，广色域图不再偏色），与 JPEG/HEIC 同款。

放弃的选项：严线（删不干净就不进）——会把 GIF/PSD/视频都排除，用户失去主要隐私信息的清理价值，换来的只是承诺更简单。

后果：GIF 的 C2PA 边界由变更探测器钉住（`GifC2paPreservationTests`，ExifTool 升级必须重跑）；视频的官方说法本来就是「删掉大部分顶层元数据」，证据缺口（带 EXIF 结构视频、C2PA、分片 MP4、MQV 真样本）单独开票补测。研究依据：`docs/research/exiftool-jxl-webp-psd-gif-apng.md`、`docs/research/exiftool-mp4-mov-m4v-3gp.md`。
